# DBPulse v0.21.2 — Windows Icon & Startup Window Update

이번 버전은 Windows에서 DBPulse를 처음 실행할 때의 사용성을 개선한 소규모 업데이트입니다.

### 달라진 점

- **DBPulse 공식 앱 아이콘 적용:** 네이비색 데이터베이스 실린더와 하늘색 Pulse 파형으로 구성된 아이콘을 Windows 실행 파일, 작업 표시줄, 제목 표시줄, 시작 메뉴, 바탕화면 바로가기와 Setup 설치 파일에 통일했습니다.
- **초기 창 크기 확대:** 기존 고정된 1440 × 900 창 대신 사용 가능한 모니터 작업 영역의 약 가로 92%·세로 90%로 중앙에서 시작합니다. 고해상도 화면에서 좀 더 넓게 표시하되, 노트북·작은 화면에서는 작업 표시줄을 침범하지 않도록 자동 조정합니다. 울트라와이드에서는 과도하게 커지지 않도록 제한합니다.
- 프로그램 설정이나 모니터링 수집 SQL을 변경하지 않습니다. 기존 등록 SQL Server, SQLite 기록, DPAPI 암호화 비밀번호와 백업 파일을 보존합니다.
- 아이콘은 16·24·32·48·64·128·256 픽셀 해상도로 빌드되어 Windows 확대 및 작업 표시줄에도 대응합니다.

### 설치 및 업데이트

1. Windows x64 전용 **`DBPulse-Setup-v0.21.2.exe`**를 다운로드하세요.
2. 앱을 정상 종료한 뒤 **기존 설치 위에 업그레이드**하세요. 데이터 폴더를 삭제하거나 프로그램을 먼저 제거하지 마세요.
3. 필요하다면 `SHA256SUMS.txt`와 설치 파일의 SHA-256 값을 비교하세요.
4. 바탕화면 아이콘이 Windows 아이콘 캐시로 인해 바로 바뀌지 않을 수 있습니다. 바탕화면 새로고침 또는 바로가기 다시 생성이 필요할 수 있습니다.

### 보안과 알려진 제한

- 설치 EXE는 **미서명** 상태입니다. Windows SmartScreen 경고가 나올 수 있으며, 코드를 서명했다고 주장하지 않습니다.
- Windows Microsoft Edge WebView2 Runtime이 필요합니다.
- 60분 연속 실행 안정성 검사는 사용자 선택으로 수행하지 않았습니다. 24시간 내구성·독립 보안 감사·실제 타사 Windows PC 전체 환경 검증도 아직 완료되지 않았습니다.
- 선택 DB CPU는 Query Store 기반 **1코어 환산 부하**이며, 단일 DB의 정확한 실시간 CPU 점유율은 아닙니다.
- SQL 원문은 클릭할 때 읽으므로 개인정보·토큰이 보일 수 있습니다. 스크린샷·SQL 원문·DPAPI 비밀번호 파일을 공개 저장소에 올리지 마세요.
- 이 버전은 시험·개인 DBA 모니터링 목적의 공개 배포본이며 운영 DB 자동복구 안전성을 보장하지 않습니다.

원본 DBPulse v0.21.1의 모니터링·성능 진단 기능은 유지됩니다.
