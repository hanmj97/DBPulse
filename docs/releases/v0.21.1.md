# DBPulse v0.21.1 — Windows 최초 공개 릴리스

DBPulse는 **Windows 로컬 설치형 SQL Server 운영 모니터링 프로그램**입니다. 이 릴리스는 GitHub에서 내려받아 설치할 수 있는 첫 번째 공개 Windows x64 배포본입니다.

### 주요 기능

- SQL Server 대상 DB 등록·연결, 실시간 DMV 요청·Blocking·Wait·Deadlock·Incident 진단
- Query Store 기반 성능 지표와 SQL Tuning Advisor, 최근 15분 통계 및 **저장된 최근 7일 쿼리 수치 이력**
- 선택 DB의 Query Store 기록 CPU 시간(ms) 및 **1개 논리 코어 환산 CPU 부하(%) 그래프**. 정확한 DB CPU 점유율이나 SQL Server 프로세스 CPU%를 뜻하지 않음
- SQL 텍스트는 사용자가 **SQL 보기**를 클릭할 때에만 로컬 SQL Server Query Store에서 가져오며 DBPulse 기록 DB에 원문을 저장하지 않음
- WebView2 네이티브 창, 내부 Java 실행 환경, 로컬 SQLite 메타데이터, Windows 사용자 DPAPI 암호화
- 새 Windows 사용자 프로필에 빈 SQLite DB를 최초 생성하는 초기화 및 기존 데이터 보존 규칙

### 설치

1. 아래 첨부된 **`DBPulse-Setup-v0.21.1.exe`**를 내려받으세요. Windows x64 전용입니다.
2. `SHA256SUMS.txt`도 내려받아 설치 파일의 SHA-256을 확인하세요.
3. Windows의 **Microsoft Edge WebView2 Runtime**이 필요합니다. 없으면 공식 Microsoft 배포본을 먼저 설치하세요.
4. 설치 파일 실행 → 시작 메뉴의 **DBPulse** 실행 → SQL Server 대상 등록 → 명시적으로 **모니터링 시작**을 누르세요. SQL Server 자격 증명은 별도로 필요하며 관리자 계정 사용을 권장하지 않습니다.
5. 기존 설치 사용자라면 먼저 앱을 정상 종료하고 기존 설치 위에 업데이트하세요. `%LOCALAPPDATA%\DBPulse` 사용자 데이터·개인 백업 파일을 삭제하지 마세요.

상세 사용 및 데이터 보관 정책: [Windows 설치 가이드](https://github.com/hanmj97/DBPulse/blob/v0.21.1/docs/USER_INSTALL_GUIDE_V021.md)

### 이번 릴리스의 실제 검증

- GitHub Actions Java / React / 통합 JAR / Python 도구 / PowerShell / Windows EXE 및 설치·제거 자동 검사 수행
- 개발자의 Windows SQL Server 테스트에서 Query Store 쿼리 조회, 튜닝 분석, Blocking·Deadlock·Wait 및 로컬 SQLite 검증 수행
- 사용자의 실제 PC에서 SQLite **10개 테이블 / 48,179개 메타데이터 레코드** 검사, 독립 백업·복원 검증, 설치 경로 사전 검사 통과
- **60분 지속 테스트는 요청에 따라 미실시**, 24시간 내구성·새로운 Windows PC 초기 실행·실서버 수집 부하 A/B 테스트도 수행되지 않음. 통과한 것으로 주장하지 않습니다.

### 알려진 제약과 보안 안내

- **설치 파일은 디지털 서명되지 않았습니다.** Windows SmartScreen이 경고할 수 있습니다. 신뢰할 수 없는 배포처의 설치 파일을 실행하거나 Windows 보안 기능을 임의로 끄지 마세요.
- 공개 배포는 시작하지만, **24시간 운영 안정성·보안 감사·업무용 운영 DB에서의 무중단/자동복구 성능을 보증하지 않습니다.** 먼저 테스트 환경에서 사용하세요.
- 로컬 SQL 텍스트에는 개인정보·토큰·SQL 리터럴이 포함될 수 있습니다. SQL 원문이나 DPAPI/SQLite 백업 파일을 GitHub 이슈에 올리지 마세요.
- Query Store가 기록하지 않은 모든 SQL을 복원할 수 없으며, 저장 이력은 실제 수집된 숫자 통계만 최대 7일 확인할 수 있습니다.
- 저장 DB가 이미 존재하는 경우 덮어쓰거나 초기화하지 않습니다. 업데이트 전에 중요한 사용자 데이터는 개인적으로 백업하세요.
- 이 공개 버전은 **자동으로 위험한 장애 복구 SQL을 실행하는 기능의 운영 적합성을 보장하지 않습니다.** 읽기 전용 모니터링·진단을 중심으로 사용하세요.
- 소스 저장소에 **오픈소스 라이선스가 별도로 정해져 있지 않습니다.** 소스·설치본 재배포 권한을 임의로 가정하지 마세요.
