# DBPulse v0.21.3 — Windows Single-Instance Hotfix

Windows x64 로컬 설치형 DBPulse의 중복 실행 문제를 수정한 패치 릴리스입니다.

## 수정 사항

- 바탕화면 또는 시작 메뉴 바로가기를 여러 번 실행해도 새 WebView2 창을 계속 생성하지 않도록 **Windows 세션별 named mutex**를 도입했습니다.
- 이미 DBPulse가 실행 중이면 후속 실행은 기존 창에 활성화 메시지를 전달하고 종료합니다.
- 최소화된 창은 원래 상태로 복원한 뒤 전면으로 활성화합니다.
- 첫 실행 준비 단계에서 연속 클릭하더라도 새 창이 생기지 않도록 활성화 메시지를 제한된 횟수로 재전송합니다.
- 기존 백엔드 재사용, SQL Server 대상 설정, SQLite 저장소, Windows DPAPI 자격증명, 아이콘 및 적응형 창 크기 로직은 유지합니다.

## 업그레이드 안내

1. Windows x64용 `DBPulse-Setup-v0.21.3.exe`와 `SHA256SUMS.txt`를 이 릴리스에서 받으세요.
2. 기존 DBPulse 창을 완전히 닫고 실행 파일이 종료된 상태에서 기존 설치 위에 업데이트하세요. 앱 데이터 폴더는 삭제하지 마세요.
3. 실행 → 바로가기를 다시 2~3회 클릭 → **창은 하나만 유지되며 기존 창이 활성화**되는지 확인하세요.
4. 창 최소화 후 다시 바로가기를 실행하여 창 복원 동작을 확인하세요.
5. SQL Server 연결·이력·SQLite 보존 여부를 기존 사용 환경에서 확인하세요.

## 보안 및 검증 한계

- EXE는 **미서명** 상태입니다. SHA-256은 무결성 검사에만 사용하며 배포자 서명을 대체하지 않습니다.
- Microsoft Edge WebView2 Runtime이 필요합니다.
- 자동 복구를 통한 파괴적 SQL 실행은 지원 또는 보증하지 않습니다.
- 60분 장시간 연속 실행 검사는 사용자 선택으로 생략되었습니다. 24시간 내구성, 타사 보안 감사, 광범위한 신규 PC 검증도 완료되었다고 주장하지 않습니다.
- DB별 Query Store CPU 지표는 1코어 환산 부하 추정이며 DB별 정확한 CPU 사용률(%)이 아닙니다.
- Windows 실제 설치 후 중복 실행 회귀 검증은 사용자 환경에서 추가 확인해야 합니다.
